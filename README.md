# Byron Mutimusakwa — Portfolio

Personal portfolio site covering Community Operations, Brand Growth, Product Marketing, and People Experience work.

Live at: https://byronmutimusakwa.github.io/byrons-community-ops-portfolio/

## Structure

- `index.html` — single-page site
- `styles.css` — all styling
- `script.js` — scroll reveal, sticky nav, ticket expand/collapse
- `assets/` — downloadable resume

## Editing

Plain HTML/CSS/JS, no build step. Open `index.html` directly or serve locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
